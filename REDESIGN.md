# PetusLauncher — редизайн (Steam-подобный)

## Требования (запрос Dimsk)
1. Убрать кнопку «выход» из шапки. Клик по нику → менюшка (Профиль / Настройки / Выйти) — как на сайте.
2. Левый сайдбар со списком игр: **PetusGDPS**, **PetusMC**. Клик → страница игры (как в Steam).
3. Иконка + имя оставить, добавить сайдбар слева.
4. **PetusMC**: кнопка «Играть» → ВНУТРЕННЕЕ окошко (модалка внутри окна, не новое окно Electron) с возможностью скопировать IP `mc.petus.ru`.
5. Баннеры для игр.
6. Блок «Обновления» снизу страницы игры → клик открывает окошко с чейнджлогом.
7. Статистика игры: наиграно времени, сколько весит, последний запуск.
8. Проверка целостности игры по хешу (человек не должен менять файлы) — сверять при запуске.

## Архитектура
- **Renderer — SPA с роутингом по играм.** Сайдбар слева, контент справа.
- Данные игр — конфиг `src/main/games.js` (id, name, banner, тип: 'gdps'|'mc', ip, changelog[], updateManifest).
- **Плейтайм/статистика** — `stats.json` в userData: `{ [gameId]: { playSeconds, lastPlayed, sizeBytes } }`. Плейтайм считаем от spawn до закрытия дочернего процесса игры.
- **Хеш-проверка**: при установке сохраняем `manifest hash` набора файлов (или размер+mtime ключевых). При «Играть» — сверяем; если не сходится → предупреждение/переустановка. MVP: хешируем GeometryDash.exe + geode/mods, сравниваем со снимком из version.json (добавим `integrity` в манифест ядра позже; пока — снимок при первой установке).
- **IPC**: `games:list`, `game:stats`, `game:play(id)`, `mc:ip`, `game:verify(id)`, `game:openFolder(id)`, `win:*`, `auth:*`.
- **Профиль-меню**: клик на ник в шапке → dropdown (Профиль → открыть gdps.petus.ru/u/<name> во внешнем браузере, Настройки → gdps.petus.ru/dashboard, Выйти).

## Файлы
- `src/main/games.js` — конфиг игр.
- `src/main/stats.js` — учёт плейтайма/размера/последнего запуска + хеш-интегрити.
- `src/main/main.js` — новые IPC, playtime tracking, verify.
- `src/main/preload.js` — новые мосты.
- `src/renderer/index.html` + `renderer.js` + `style.css` — сайдбар, страницы игр, модалки.
